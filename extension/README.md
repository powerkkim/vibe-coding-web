# Vibe Coding 브라우저 도우미 (크롬 확장)

Vibe Coding 챗봇이 내 크롬의 "Vibe" 탭 그룹 안에서 사이트를 열고, 읽고, 클릭·입력하게 해 주는 확장입니다.

## 설치 (개발자 모드)

1. 앱의 사이드바 아래 **브라우저 확장 설치** → `vibe-browser-extension.zip` 받기 → 압축 풀기(폴더는 지우지 않기)
2. `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램 로드** → 푼 폴더 선택
4. 앱 새로고침 → 사이드바에 "브라우저 확장 vX 연결됨"

업데이트: 새 zip 으로 폴더 내용을 바꾼 뒤 확장 카드의 새로고침(↻).

## 동작

- 앱(`powerkkim.github.io`, `localhost:5173`, `localhost:4186`)에서 온 메시지만 받는다.
- 이 확장이 연 "Vibe" 그룹의 탭만 조작한다. http(s) 페이지만 연다.
- 클릭·입력·스크린샷은 `chrome.debugger`(CDP). 조작 중에는 크롬이 '디버깅 중' 띠를 띄우고, 취소를 누르면 1분간 조작을 거부한다.
- 처음 여는 사이트와 저장·삭제·전송 같은 동작의 확인은 앱이 받는다.
